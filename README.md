# ClauseBridge

Contract and obligation management built with [Univer](https://univer.ai).

Upload a contract, review the deadlines, deliverables, parties and payment terms that Ling 3.2 Flash suggests, and confirm the ones that are right. Confirmed terms become obligations with an owner, a status and evidence, tracked in Univer Sheets and reported in Univer Docs.

Work in progress. See [`docs/PROPOSAL.md`](docs/PROPOSAL.md) for what is being built and [`docs/CLIENT_SCOPE.md`](docs/CLIENT_SCOPE.md) for how each part of the proposal is met.
